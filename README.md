# React Native Form Components

A practical project exploring form components in React Native using Expo and TypeScript.

## Features
- Text inputs for name and email
- Radio buttons for gender selection
- Course selection
- Checkbox for terms acceptance
- Switch for notifications
- Form submission and console logging
- React state management using `useState`

## Technologies
- React Native
- Expo
- TypeScript
- React Hooks

## Run Locally

```bash
npm install
npx expo install
npx expo start
```

## Purpose

To learn how to build interactive forms, manage input state, handle user events, and prepare form data for backend integration.
